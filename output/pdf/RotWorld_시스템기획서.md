# RotWorld 시스템 기획서

## 1. 게임 개요

생존자의 선택이 도시 전체의 변화를 만든다

RotWorld는 좀비 사태가 시작된 현대 도시를 배경으로 하는 생존·신 시뮬레이션 게임이다. 인간들은 각자의 상태와 성격에 따라 살아남기 위한 행동을 선택하고, 플레이어는 그 과정에 관찰자이자 개입자로 참여한다.

| 항목 | 게임의 기본 구성 |
| --- | --- |
| 장르·플랫폼 | 생존·신 시뮬레이션 / 웹 브라우저 |
| 배경 | 인간과 좀비가 함께 존재하는 현대 도시 |
| 시작 규모 | 인간 약 30~50명이 생활하는 작은 동네 |
| 시각 표현 | 위에서 내려다보는 탑다운 픽셀 아트 |
| 플레이 방식 | 도시 관찰·개입 / 특정 인간에 빙의해 행동 선택 |

### 핵심 경험: 관찰과 선택

인간은 화면을 채우는 장식이 아니라 상태와 경험을 유지하는 개별 인물이다. 같은 위험에 마주쳐도 성격·능력·소지품에 따라 도주하거나 싸우며, 플레이어는 정보창에서 선택의 실제 근거를 확인한다.

### 서로 연결되는 시스템

| 핵심 요소 | 게임에 미치는 영향 |
| --- | --- |
| 물자 고갈 | 남은 물자가 소비되며 생존을 위한 탐색 필요 |
| 소음과 좀비 | 이동·탐색·경고가 좀비 접근을 유발 |
| 전투와 감염 | 도주·교전 결과가 부상·물림·변이로 연결 |
| 개인별 학습 | 경험으로 얻은 지식이 이후 행동을 변화시킴 |

주요 키워드: 자율 생존 · 인간 빙의 · 한정된 물자 · 소음 · 감염 · 학습

## 2. 플레이 방식과 회차

도시를 바꾸는 권한과 한 인물의 생존

플레이어는 도시 전체의 상태와 인간의 판단을 관찰하고, 개체를 생성하거나 수치를 바꾸어 결과에 개입한다. 특정 인간에 빙의하면 그 인물의 행동을 직접 선택하며, 다른 인간은 자율 판단을 유지한다.

### 플레이어의 권한

| 기능 | 할 수 있는 일 |
| --- | --- |
| 세계 구성 | 건물을 건설하고 배치 |
| 개체 생성 | 인간·좀비 추가 / 원하는 시간·장소에 좀비 생성 |
| 직접 명령 | 인간과 좀비의 행동 지정 |
| 인간 조정 | 욕구·성격·능력·관련 판단 기준 변경 |
| 좀비 조정 | 이동 속도·소음 민감도 변경 |
| 상태 관찰 | 개체의 상태·현재 행동·선택 이유 확인 |

### 메인 캐릭터 설정과 시작

새 게임 → 메인 캐릭터의 스탯·성격·특성 설정 → 세계 진입 → 생존 플레이. 메인 캐릭터는 잠시 빙의한 대상과 구분되며 해당 회차의 생존 기준 인물이다.

### 메인 캐릭터 사망 시 회차 종료

메인 캐릭터가 사망하면 캐릭터 진행과 소지품뿐 아니라 누적된 세계 변화와 플레이 진행도 초기화한다. 다른 생존자로 옮겨 같은 회차를 이어갈 수 없으며, 다른 대상을 제어하고 있어도 종료 조건은 동일하다.

핵심 규칙: 메인 캐릭터 사망 = 회차 종료·진행 초기화

## 3. 캐릭터 생성: 스탯과 성격

스탯은 수행 능력, 성격은 선택 성향

캐릭터 생성은 스탯 배분, 성격 설정, 특성 선택으로 구성된다. 능력이 높은 인간과 위험을 감수하는 인간은 서로 다르며, 수행 능력과 행동 선호를 나누어 다양한 생존 방식을 만든다.

### 스탯 6종

| 스탯 | 핵심 역할 |
| --- | --- |
| 근력 | 근접 공격·밀치기의 위력과 무거운 물건 취급 |
| 민첩 | 방향 전환·회피·위험에서 빠져나오는 능력 |
| 지구력 | 달리기·전투를 지속하는 단기 활동 능력 |
| 지각 | 위협·소리·탐색 단서를 알아채는 능력 |
| 침착성 | 공포로 생기는 행동 수행 불이익 완화 |
| 학습력 | 경험을 지식으로 정리하고 숙련을 얻는 속도 |

### 성격 5축

| 성격 축 | 선택에 반영되는 성향 |
| --- | --- |
| 위험 감수 / 공격 성향 | 안전과 위험 감수 / 회피와 선제 전투 |
| 이타성 / 규칙 준수 | 자신과 타인의 생존 / 타인의 소유물에 대한 태도 |
| 비축 성향 | 당장 필요한 물자와 미래 부족에 대비한 확보 |

성격은 낮음·보통·높음으로 선택하며 별도 포인트 비용을 두지 않는다. 위험 감수와 공격 성향은 독립적으로 적용되고, 직접 조작 중에는 성격이 플레이어의 선택을 강제로 빼앗지 않는다.

스탯과 전투 숙련은 별개다. 높은 지각은 장애물을 무시하지 않으며, 높은 학습력도 경험하지 않은 지식을 자동으로 제공하지 않는다.

## 4. 캐릭터 생성: 특성

상황별 장점과 단점으로 생존 방식을 구분한다

특성은 특정 상황에서 작동하는 개인의 장단점이다. 소음·물자 소비·수면·회복 등 서로 다른 부담을 조합하여 캐릭터의 생존 방식을 정한다. 기본 특성 포인트에 단점 선택으로 얻는 포인트를 더해 장점을 선택한다.

### 특성 12종과 효과

| 분야 | 특성 | 효과 방향 |
| --- | --- | --- |
| 이동 소음 | 조용한 발걸음<br>요란한 발걸음 | 걷기 소음 감소<br>걷기·달리기 소음 증가 |
| 물품 취급 | 정리 습관<br>서투른 손놀림 | 물품 획득·보관 시 이전 시간 감소<br>물품 획득·보관 시 이전 시간 증가 |
| 식량 소비 | 소식가<br>대식가 | 허기 증가 속도 감소<br>허기 증가 속도 증가 |
| 수면 | 적은 수면<br>많은 수면 | 수면 중 피로 회복 속도 증가<br>수면 중 피로 회복 속도 감소 |
| 일반 부상 | 빠른 회복<br>느린 회복 | 일반 부상 회복 속도 증가<br>일반 부상 회복 속도 감소 |
| 환경·공포 | 어둠에 익숙함<br>폐쇄 공간 공포 | 어두운 장소의 공포 증가 속도 감소<br>좁은 실내에서 공포 증가 |

### 선택 제한과 적용 범위

동일 특성의 중복 선택과 상반된 특성의 동시 선택을 금지한다. 어둠에 익숙함과 폐쇄 공간 공포는 서로 다른 환경에 작용하므로 상반된 한 쌍으로 취급하지 않는다.

효과가 없는 단점으로 포인트를 얻을 수 없으며, 관련 기능이 제공되는 특성만 선택할 수 있다. 일반 부상 회복 특성은 감염을 치료하지 않고, 어떤 스탯이나 특성도 물림 무효·감염 면역을 제공하지 않는다.

핵심 구분: 스탯 = 능력 / 성격 = 선호 / 특성 = 상황별 장단점

## 5. 생존 상태와 행동

즉각적인 위험 대응을 생존 욕구 해결보다 우선한다

인간은 허기·갈증·피로·공포와 주변 위험을 함께 고려한다. 상태는 행동의 우선순위뿐 아니라 전투 수행과 물품 취급에도 영향을 주며, 욕구 하나의 숫자만으로 모든 행동을 결정하지 않는다.

### 인간의 생존 상태

| 상태 | 의미와 대응 |
| --- | --- |
| 허기 | 식량 필요 / 음식 섭취·식량 확보 |
| 갈증 | 수분 필요 / 물 확보·수분 섭취 |
| 피로 | 장기적으로 누적되는 활동 부담 / 안전한 곳에서 수면 |
| 공포 | 직접 인지한 위협·사건·환경에 대한 심리 반응 |
| 위험도 | 현재 위치·인지한 위협·탈출 경로를 바탕으로 평가 |

### 상태에 따른 생존 행동

안전 확보 → 긴급한 생존 욕구 해결 → 향후 물자·거처 확보 → 여유 행동을 기본 흐름으로 둔다. 위험 중에는 배고프다는 이유만으로 식사를 시작하지 않으며, 위험이 발생하면 현재 행동을 다시 평가한다.

| 행동 | 연결되는 조건 |
| --- | --- |
| 식사·물 섭취 | 보유 물품으로 해결하거나 추가 물자 탐색 |
| 휴식·수면 | 장기 피로와 단기 활동 여력을 구분해 관리 |
| 은신·도주·전투 | 현재 몸 상태·능력·공포와 주변 위협 비교 |

### 공포와 안전의 구분

공포는 인간의 심리 상태이며 안전은 상황에 대한 위험 평가다. 인간은 보지 못한 좀비의 위치를 근거 없이 사용하지 않는다. 직접 조작 중에도 수행 불이익은 적용하지만 공포만으로 자동 도주·비명·명령 취소를 강제하지 않는다.

정보창: 생존 상태 · 변화 원인 · 적용 중인 불이익 · 행동 선택 이유

## 6. 상태 표시와 판단 정보

숫자 대신 신체 상태와 활동 여력을 읽는다

체력과 스태미나의 수치는 내부 계산에 사용하되 플레이어 화면에는 현재값·최댓값·백분율과 비율 게이지를 표시하지 않는다. 플레이어는 상태 텍스트와 변화 원인으로 위험과 회복 여부를 판단한다.

### 상태와 변화 방향의 표시

| 대상 | 표시하는 정보 |
| --- | --- |
| 신체 상태 | 신체 손상 수준 / 부상·감염은 별도로 표시 |
| 활동 여력 | 현재 활동에 사용할 수 있는 힘 / 장기 피로와 구분 |
| 변화 방향 | 회복·안정·악화 또는 회복·유지·소모 |
| 상세 안내 | 확인된 원인·대처·현재 행동 가능 여부 |

변화 방향은 실제 증감에 연결한다. 최대치만 달라진 것을 회복이나 소모로 표현하지 않으며, 상태가 양호해도 부상·감염이 없다는 뜻은 아니며, 모든 행동이 가능하다는 뜻도 아니다.

### 실제 근거에 연결되는 정보창

| 정보 범주 | 확인할 내용 |
| --- | --- |
| 개인 정보 | 이름·나이·사태 이전 직업·기존 집·돈 |
| 현재 상태 | 소지품·성격·욕구·관련 능력 |
| 행동 정보 | 현재 행동·선택 이유 / 플레이어 선택과 AI 판단 구분 |
| 지식 정보 | 학습한 사실·학습 근거 |
| 감염 정보 | 감염 여부·변이까지 남은 시간 |

### 플레이어의 정보와 인간의 지식

플레이어가 보는 전체 정보가 모든 인간에게 자동으로 주어지지 않는다. 판단 설명은 해당 인간의 실제 관찰·기억·학습 내용에 근거해야 하며, 캐릭터가 모르는 사실을 이유로 제시하지 않는다.

핵심 원칙: 상태를 이해할 수 있는 표현 + 실제 판단 근거의 일치

## 7. 도시와 한정된 물자

세계에 남은 재고를 탐색하고 소비한다

도시는 인간이 안전과 물자를 확보하는 현대 생활 공간이다. 집·편의점·마트·회사·공장이 존재하지만, 사태 이전의 정상적인 출근·급여·생산·배송 체계는 생존 행동의 중심이 아니다.

### 물자의 변화

| 단계 | 핵심 규칙 |
| --- | --- |
| 남은 재고 | 세계에 존재하는 한정된 물자를 탐색 |
| 획득 | 원래 장소의 재고가 줄고 인간의 소지품으로 이동 |
| 사용·소비 | 해당 물품을 실제로 차감하고 관련 욕구 해소 |
| 고갈 | 같은 장소에서 해당 물품을 더 얻을 수 없음 |

물자를 사용하면 세계에 남은 물자의 총량이 줄어든다. 생산, 공장과 매장 사이의 배송, 자동 재입고, 자연 재생산이 없으므로, 동일 장소를 반복 방문해도 소비한 물자가 저절로 돌아오지 않는다.

### 물자 확보의 판단 요소

| 고려 요소 | 행동에 연결되는 의미 |
| --- | --- |
| 허기·갈증 | 현재 충족해야 하는 생존 욕구 |
| 성격·공포 | 확보를 위해 위험을 감수할 정도 |
| 주변 위험 | 물자를 얻는 동안 마주할 위협 |
| 타인의 소유 여부 | 물품을 가져갈지 판단하는 요소 |

### 개인의 정보와 현실의 차이

인간은 플레이어가 아는 모든 물자 위치와 위험을 자동으로 알지 못한다. 목격하지 않은 재고 변화가 모든 인간에게 동시에 전달되지 않으며, 기존 집도 안전한 거처임을 보장하지 않는다.

핵심 규칙: 획득은 재고 이동 / 소비는 수량 감소 / 고갈 후 자동 보충 없음

## 8. 좀비·소음·개인별 학습

경고는 인간을 돕지만 좀비도 끌어들인다

좀비는 자율적으로 돌아다니며 소음에 민감하게 반응한다. 인간의 이동과 탐색, 목소리와 비명, 외치는 경고와 물건 파손은 좀비의 판단과 접근에 영향을 주는 소음원이 된다.

### 소음이 만드는 생존 부담

| 소음원 | 생존 상황과의 연결 |
| --- | --- |
| 이동·탐색 | 물자를 확보하는 행동도 소음 위험을 동반 |
| 목소리·비명 | 인간의 반응이 주변 좀비를 자극 |
| 외치는 경고 | 주변 인간의 대피를 돕는 동시에 좀비 유인 |
| 물건 파손 | 행동의 결과가 추가 소음으로 이어짐 |

플레이어는 좀비의 이동 속도와 소음 민감도를 조정할 수 있다. 이 개입은 인간이 처한 위험과 대응의 결과를 관찰하는 수단이 된다.

### 소음의 위험을 배우는 인간

| 지식 상태 | 좀비 발견 시 행동 |
| --- | --- |
| 학습 전 | 소리쳐 주변에 경고할 수 있음 |
| 경험 | 경고 소리에 좀비가 끌려오는 결과를 겪음 |
| 학습 후 | 소음의 위험을 알게 되면 소리치는 경고 중단 |

### 지식은 개인별로 관리

좀비 사태가 시작된 세계라도 모두가 좀비의 특성을 완전히 아는 것은 아니다. 인간은 경험을 통해 배우며, 한 사람이 얻은 지식이 모든 인간에게 일괄 적용되지 않는다. 정보창은 배운 사실과 그 근거를 함께 보여준다.

핵심 연결: 소리 → 좀비 접근 → 경험 → 학습 → 이후 행동 변화

## 9. 전투·감염·변이

전투가 곧 물림은 아니며, 물림이 성공하면 감염된다

인간은 좀비를 만나면 도망가거나 공격할 수 있다. 능력·성격·몸 상태·공포·소지품뿐 아니라 좀비 수·거리·탈출 가능성을 고려하며, 교전 중 위험이 커지면 도주로 전환할 수 있다.

### 전투 결과의 구분

| 결과 | 의미 |
| --- | --- |
| 제압 | 물리지 않고 좀비를 쓰러뜨릴 수 있음 |
| 회피·방어·탈출 | 공격을 피하거나 막고 위험에서 벗어남 |
| 일반 부상 | 다칠 수 있으나 부상만으로 감염되지 않음 |
| 물림 | 좀비의 물림 성공 시 감염 |

인간은 맨손이나 소지품 중 공격 가능한 물건을 사용한다. 공격 성공·반격·물림을 구분하고, 전투와 도주 판단의 실제 근거를 정보창에 표시한다.

### 감염부터 변이까지

| 단계 | 감염자 상태 | 주변 인간의 인식 |
| --- | --- | --- |
| 잠복기 | 눈에 보이는 증상 없음 | 감염 사실 자동 인지 불가 |
| 증상기 | 관찰 가능한 증상 발생 | 인지한 인간이 경계·회피 |
| 변이 | 인간이 좀비로 전환 | 목격한 좀비 위협에 반응 |

### 감염 정보의 차이

플레이어는 감염 여부와 변이까지 남은 시간을 항상 확인할 수 있다. 주변 인간은 그 정보를 자동으로 얻지 못하며 직접 인지한 증상에 반응한다. 멀리 있는 인간까지 동시에 감염자를 알아보지 않는다.

핵심 규칙: 물림 성공 → 감염 → 일정 시간 경과 → 좀비 변이
