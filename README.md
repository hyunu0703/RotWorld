# RotWorld

실행 사이트: https://rot-world.hyunu0703.chatgpt.site

도시·이동 시제품: 인간 12명과 건물 12개, 길 찾기, 인간 선택과 상태 확인, 정지·1/2/4배속, 지도 이동·확대·추적.

## 제작과 검증

GameDesign.md 전체와 AGENTS.md를 먼저 읽는다. 로컬호스트 개발·미리보기 서버를 사용하지 않는다. 소스 편집과 정적 빌드 후 기존 Sites 프로젝트에 게시하고 지정 사이트에서 브라우저 동작을 확인한다.

- 의존성: `pnpm install --frozen-lockfile`
- 타입 검사와 정적 빌드: `pnpm build`
- 시뮬레이션 검증(Node 24): `pnpm test`
- 게시 대상: `.openai/hosting.json`의 기존 프로젝트와 `dist/`.

`src/simulation`은 화면과 독립적인 상태·시간·길 찾기, `src/rendering`은 PixiJS 지도와 카메라, `src/ui`는 정보창과 조작, `src/assets`는 재사용 픽셀 텍스처, `src/data`는 시제품 수치를 관리한다.

드래그·방향키로 지도 이동, 휠·＋/−로 확대·축소, F로 전체 보기. 인간 클릭 또는 인간 목록에서 선택한다. 지도에 포커스한 상태에서 Space로 정지·재개한다. 모바일은 드래그·두 손가락 확대 및 버튼을 지원한다.

캐릭터 생성 화면에서 이름·스탯·성격·특성을 설정한 뒤 최종 확인하고 세계에 진입한다. 상단 단계·이전·다음 이동 시 설정을 유지하며 포인트·충돌·선택 수 제한을 적용한다. 선택값은 메인 캐릭터 데이터와 인물 정보창에 반영된다. 미구현 생존·전투·AI 효과는 관련 시스템 연결 후 작동한다.

메인 캐릭터는 지도 표식·목록·정보창으로 구분하며 주인공 찾기 버튼으로 돌아갈 수 있다. 새 회차는 초기화 확인 후 생성부터 다시 시작한다. 사망 사건 수신에 따른 회차 폐기는 자동 검증되지만 실제 전투·부상은 아직 없다. 새로고침 시 시제품 상태는 초기화된다.

4단계 소스에는 게임 시간에 따른 허기·갈증·피로, 간식·식사·물의 유한 재고와 실제 획득·보관·소비, 식사·음수·휴식·수면이 연결되어 있다. 인간 선택 후 정보창에서 행동과 장소를 지정한다. 지도 건물 클릭으로 장소를 선택할 수도 있다. 장소 행동은 입구까지 이동한 뒤 실행하며 완료 전 중단에는 물자를 차감하지 않는다. 자동 재입고는 없다. 식량 소비·수면·물품 취급 특성은 적용되며 5단계 자율 생존은 아래 범위를 따르며 좀비·체력·스태미나·전투·저장은 후속 단계다.

5단계 소스는 개인별 시각·장소/재고/위험 기억과 물자 확보·섭취·수면·탐색 AI를 제공한다. NPC는 자율 생존으로 시작하고 메인 캐릭터는 직접 지시로 시작한다. 정보창에서 자율 생존을 전환하며 직접 명령은 자율 행동을 끈다. 개인 기억·후보 점수·최근 판단 이유도 확인할 수 있다. 지각·위험 감수·비축 성향이 실제 관찰·선택에 반영된다. 실제 좀비·소음과 추격·공포는 6단계이며 현재 위험 목록은 비어 있다. AI의 임시 기본값은 GameDesign.md 12절에 기록한다. src/ai는 화면과 독립적으로 동작한다.

개인 정보 차이·고갈 재판단·욕구 목표·성향별 선택·수면·수량 보존·위험 대응 기반·하루 자율 진행을 포함해 자동 검증 41개를 제공한다. 이번 변경은 커밋·푸시·배포 승인 대기다. Sites의 소스 동기화 절차는 커밋을 생성하므로 명시적 승인 전에는 실행하지 않는다. 로컬호스트는 사용하지 않으며 사이트 브라우저 검증은 승인된 배포 후 수행한다.
